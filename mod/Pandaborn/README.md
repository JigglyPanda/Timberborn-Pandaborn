# Pandaborn - Timberborn 1.x

Every Folktail becomes a giant panda and every Iron Teeth beaver a red panda.

* **Panda bodies** for adults and kits, on every original animation. Every job, swim, zipline, dance and sleep
  works.
* **Coats:** 5 adult and 3 kit coats per faction.
  * Giant pandas: classic, cream, snowy, honey, and a rare brown Qinling.
  * Red pandas: classic, chestnut, golden, soot-grimed, and a rare cinnamon.
* **Real fur** on pandas near the camera:
  * soft layered strands and fuzzy outlines
  * fur that trails when pandas move
  * wet and badwater-matted fur
* **New portraits** for both factions.
* **Any faction, any panda.** Folktails default to giant pandas and Iron Teeth to red pandas, but each can be
  switched. Modded factions (Emberpelts, Leaf Coats, Badfurs, ...) can be giant pandas, red pandas, or keep their
  own colours on the panda body.

## Settings
* With the **Mod Settings** mod installed: *Settings > Mod settings > Pandaborn*. The options are fur on/off,
  quality, distance, max furry pandas, fur length, fuzzy outlines and fur motion, plus which animal each faction is.
  Fur changes apply instantly; faction changes apply to new colonists (reload the save to update everyone).
* Without it: edit `PandaFurSettings.txt` in this folder.

## Compatibility
* The original beaver texture layout is kept, so outfits, hats, injuries, contamination and carried goods still line
  up.
* Pandaborn replaces `Characters/Beaver/*`, `Materials/Beavers/*` and `Sprites/Avatars/*`. Other mods that replace
  the same files conflict with it, and whichever loads later wins.
* Purely visual: safe to add to or remove from any save.

Source code, the art pipeline and the AI disclosure: https://github.com/JigglyPanda/Timberborn-Pandaborn
